Installing Java version for Windows (Oracle JDK)
After unpacking the zip file in your desired location, configure it to add to PATH variable:

    export JAVA_HOME="/C/Program Files/jdk-11.0.25"
    export PATH="${JAVA_HOME}/bin:${PATH}"

Verify it works: 
    java --version

--------------------------------------------------------

hADOOP BINARIES

```
$ HADOOP_VERSION="3.2.0"
PREFIX="https://raw.githubusercontent.com/cdarlint/winutils/master/hadoop-${HADOOP_VERSION}/bin/"

FILES="hadoop.dll hadoop.exp hadoop.lib hadoop.pdb libwinutils.lib winutils.exe winutils.pdb"

for FILE in ${FILES}; do
  curl -o "${FILE}" "${PREFIX}/${FILE}";
done
```

Note: add a file if you want to specify directory of download i.e. >>>>  curl -o "file_path_name"

INSTALLING Spark
Select version 3.3.2 and unpack it in a folder

export SPARK_HOME="/C/Program Files/spark-3.3.2-bin-hadoop3"
export PATH="${SPARK_HOME}/bin:${PATH}"
